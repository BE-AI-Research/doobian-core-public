The Doobian Core OS repository for the public.
> # Doobian Core
>
> Doobian Core is a modular Linux distribution that lets you build your own operating system from a curated set of components. It is built on Devuan and Debian as parallel upstream bases, with the chosen template determining which one your install tracks.
>
> Pick a blessed template and Doobian makes the decisions for you — five validated configurations covering systemd-free desktop, standard Debian-with-systemd, headless node, server, and a power-user Custom Build path. Pick Custom Build and choose every component yourself: init system, network stack, display server, session manager, sound server, logger, scheduler, bootloader. Both paths produce a real Doobian system; neither is more legitimate than the other.
>
